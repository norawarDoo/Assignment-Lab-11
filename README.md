# Assignment 5 — Bank DApp

เว็บแอปธนาคารแบบกระจายศูนย์ (Decentralized Application หรือ DApp) สำหรับฝาก ถอน และตรวจสอบยอด ETH ที่บันทึกไว้ใน Smart Contract ผู้ใช้เชื่อมต่อกระเป๋า MetaMask เพื่ออ่านข้อมูลและยืนยันธุรกรรมบน Ethereum-compatible network

- **ชื่อ:** นรวัฒน์ ดูการดี

## วัตถุประสงค์การเรียนรู้

- เข้าใจบทบาทของ Smart Contract ในการเก็บและจัดการข้อมูลบนบล็อกเชน
- ทดลองเขียนและ Deploy Contract ด้วย Solidity และ Remix
- เชื่อมต่อหน้าเว็บกับ MetaMask ผ่าน ethers.js
- เรียกใช้ฟังก์ชันอ่านข้อมูลและส่งธุรกรรมที่ต้องใช้ Gas

## ความสามารถของระบบ

- เชื่อมต่อ MetaMask และแสดง address ของบัญชีและเครือข่ายปัจจุบัน
- ตั้งค่าและบันทึก Contract Address ไว้ในเบราว์เซอร์
- ฝาก ETH เข้า Smart Contract และถอน ETH ตามยอดของบัญชีที่เชื่อมต่อ
- ตรวจสอบยอด ETH ของบัญชีและรีเฟรชยอดได้
- แสดงผลการทำรายการและลิงก์ไปยัง Block Explorer เมื่อเครือข่ายนั้นรองรับ

> ยอดเงินที่แสดงเป็นยอดของบัญชีปัจจุบันภายใน Smart Contract ไม่ใช่ยอด ETH ในกระเป๋า MetaMask

## เทคโนโลยีและไฟล์ในโปรเจกต์

| ไฟล์ | รายละเอียด |
| --- | --- |
| `Bank.sol` | Smart Contract ภาษา Solidity สำหรับฝาก ถอน และตรวจสอบยอด |
| `index.html` | โครงสร้างหน้าเว็บและองค์ประกอบสำหรับใช้งาน |
| `style.css` | รูปแบบหน้าเว็บและการรองรับหน้าจอขนาดต่าง ๆ |
| `app.js` | เชื่อมต่อ MetaMask, ethers.js และ Smart Contract |
| `README.md` | คำอธิบายและคู่มือการติดตั้ง/ทดลองใช้งาน |

หน้าเว็บใช้ ethers.js v6.15.0 จาก CDN จึงไม่ต้องติดตั้งแพ็กเกจ Node.js แต่ต้องเชื่อมต่ออินเทอร์เน็ต

## หลักการทำงาน

1. ผู้ใช้เลือกเครือข่ายและบัญชีใน MetaMask แล้วเชื่อมต่อกับหน้าเว็บ
2. ผู้ใช้กรอก Contract Address ที่ Deploy ไว้บนเครือข่ายเดียวกัน
3. หน้าเว็บตรวจสอบ Address และยืนยันว่ามี Smart Contract อยู่ที่ Address นั้น
4. การตรวจสอบยอดเรียก `checkBlance()` แบบอ่านข้อมูล ไม่ต้องส่งธุรกรรม
5. การฝากและถอนส่งธุรกรรมผ่าน MetaMask ผู้ใช้ต้องตรวจสอบและยืนยันธุรกรรม พร้อมจ่ายค่า Gas
6. เมื่อธุรกรรมได้รับการยืนยัน หน้าเว็บจะอ่านยอดล่าสุดจาก Contract อีกครั้ง

Contract Address จะถูกเก็บใน `localStorage` ของเบราว์เซอร์เพื่อใช้ครั้งถัดไป ไม่ได้เก็บ Private Key ไว้ในแอป

## ฟังก์ชันใน Smart Contract

| ฟังก์ชัน/รายการ | การทำงาน |
| --- | --- |
| `deposit()` | รับ ETH และเพิ่มยอดของผู้เรียก โดยจำนวนต้องฝากมากกว่า 0 |
| `withdraw(uint256 amount)` | ถอน ETH จากยอดของผู้เรียก เมื่อจำนวนมากกว่า 0 และไม่เกินยอดคงเหลือ |
| `checkBlance()` | อ่านยอด ETH ของผู้เรียก |
| `Deposit` event | บันทึกเหตุการณ์ฝาก พร้อม address และจำนวนเงิน |
| `Withdraw` event | บันทึกเหตุการณ์ถอน พร้อม address และจำนวนเงิน |

ชื่อ `checkBlance()` สะกดตามโจทย์ที่ใช้ทำงานนี้ จึงต้องใช้ชื่อนี้ทั้งใน Contract และหน้าเว็บ

## สิ่งที่ต้องเตรียม

- เว็บเบราว์เซอร์ที่รองรับส่วนขยาย MetaMask
- MetaMask และ ETH สำหรับทดสอบบน Testnet เพื่อจ่ายค่า Gas
- Contract Address ของ `Bank.sol` ที่ Deploy บนเครือข่ายที่เลือก
- อินเทอร์เน็ตสำหรับโหลด ethers.js จาก CDN

แนะนำให้ทดลองบน Testnet เช่น Sepolia หรือ Hoodi และใช้ Test ETH เท่านั้น การใช้ Mainnet อาจทำให้เสียเงินจริง

## วิธี Deploy Smart Contract

1. เปิด [Remix IDE](https://remix.ethereum.org)
2. สร้างไฟล์ `Bank.sol` แล้วคัดลอกโค้ดจากโปรเจกต์นี้ลงไป
3. เปิด **Solidity Compiler** เลือก Compiler เวอร์ชัน `0.8.x` แล้ว Compile
4. เปิด **Deploy & Run Transactions** และเลือก Environment ที่เชื่อมกับ MetaMask เช่น **Injected Provider - MetaMask**
5. เลือกเครือข่าย Testnet ใน MetaMask และตรวจสอบว่าบัญชีมี Test ETH สำหรับจ่าย Gas
6. กด **Deploy** และยืนยันธุรกรรมใน MetaMask
7. เมื่อ Deploy สำเร็จ ให้คัดลอก Contract Address ที่ Remix แสดงไว้

ต้อง Deploy Contract ก่อนจึงจะฝากหรือถอนเงินได้ การเผยแพร่เฉพาะหน้าเว็บไม่ได้ Deploy Smart Contract ให้โดยอัตโนมัติ

## วิธีเปิดและทดลองใช้งานในเครื่อง

1. เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วเริ่ม Local Web Server:

   ```bash
   python3 -m http.server 8000
   ```

   หรือเปิดโปรเจกต์ด้วยส่วนขยาย Live Server ใน VS Code

2. เปิด `http://localhost:8000` ในเบราว์เซอร์
3. ใน MetaMask เลือกเครือข่ายเดียวกับที่ Deploy Contract
4. กรอก Contract Address แล้วกด **บันทึก**
5. กด **เชื่อมต่อ MetaMask** และอนุญาตการเชื่อมต่อ
6. ตรวจสอบยอดที่แสดง แล้วทดลองฝาก เช่น `0.001` ETH
7. ยืนยันธุรกรรมใน MetaMask และรอให้เครือข่ายยืนยัน
8. ทดลองถอนจำนวนที่น้อยกว่ายอดคงเหลือ เช่น `0.0005` ETH

ปิด Local Web Server ด้วย `Ctrl+C` ใน Terminal เมื่อเลิกใช้งาน

## เผยแพร่ด้วย GitHub Pages

1. สร้าง GitHub repository สำหรับโปรเจกต์
2. Push ไฟล์ `index.html`, `style.css`, `app.js`, `Bank.sol` และ `README.md` ไว้ที่ root ของ branch ที่ต้องการเผยแพร่
3. ไปที่ **Settings → Pages**
4. ในส่วน **Build and deployment** เลือก **Deploy from a branch**
5. เลือก branch เช่น `main` และโฟลเดอร์ `/(root)` แล้วกด **Save**
6. รอให้ GitHub Pages เผยแพร่ จากนั้นเปิด URL ที่ GitHub แสดง
7. เชื่อมต่อ MetaMask และกรอก Contract Address ก่อนใช้งาน

URL มักมีรูปแบบ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repository>/` ทั้งนี้หน้าเว็บที่เผยแพร่และ Contract ต้องอยู่บนเครือข่ายที่ตรงกัน

## เครือข่ายที่แสดงชื่อ/ลิงก์ Explorer ในหน้าเว็บ

หน้าเว็บมีชื่อเครือข่ายสำหรับ Ethereum Mainnet, Sepolia, Holesky, Hoodi และ Localhost รวมถึงลิงก์ Block Explorer สำหรับ Mainnet, Sepolia, Holesky และ Hoodi หากใช้เครือข่ายอื่น หน้าเว็บจะแสดง Chain ID แทนชื่อเครือข่าย

## การแก้ปัญหาเบื้องต้น

- **ไม่พบ MetaMask:** เปิดหน้าเว็บในเบราว์เซอร์ที่ติดตั้ง MetaMask หรือใช้เบราว์เซอร์ภายในแอป MetaMask บนมือถือ
- **ไม่พบ Smart Contract:** ตรวจสอบ Contract Address และตรวจสอบว่า MetaMask ใช้เครือข่ายเดียวกับตอน Deploy
- **ยอดไม่แสดง/เชื่อมต่อไม่ได้:** ตรวจสอบว่าได้เชื่อมต่อ MetaMask และบันทึก Contract Address ที่ถูกต้องแล้ว
- **ธุรกรรมไม่ผ่าน:** ตรวจสอบ Test ETH สำหรับค่า Gas และยอดคงเหลือใน Contract ก่อนถอน
- **ผู้ใช้ยกเลิกคำขอ:** เปิด MetaMask และยืนยันคำขอ หากต้องการส่งธุรกรรม
- **หน้าเว็บโหลด ethers.js ไม่ได้:** ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต เนื่องจากไลบรารีโหลดจาก CDN

## ข้อจำกัดและข้อควรระวัง

- Contract นี้เป็นตัวอย่างเพื่อการศึกษา ไม่ได้ออกแบบหรือผ่านการตรวจสอบสำหรับเก็บเงินจริง
- ยอดเงินแยกตาม address ที่เรียก Contract แต่ ETH จริงถูกเก็บรวมอยู่ใน Contract
- การส่งธุรกรรมทุกครั้งต้องได้รับการยืนยันจาก MetaMask และอาจมีค่า Gas
- การเปลี่ยนบัญชีหรือเครือข่ายใน MetaMask จะทำให้หน้าเว็บโหลดใหม่เพื่อเชื่อมต่อสถานะล่าสุด
- อย่าเปิดเผย Seed Phrase หรือ Private Key ให้เว็บไซต์หรือบุคคลอื่น
